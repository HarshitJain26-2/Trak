## C. Android API 36 / Google Play Compatibility

**Requirement (verified against Google Play policy):** Starting **August 31, 2026**, new apps and app updates must target **Android 16 (API level 36)** or higher.

**Current state:** Expo SDK 54 defaults to **targetSdk/compileSdk = 35** (verified in `node_modules/expo-modules-autolinking/.../ExpoRootProjectPlugin.kt` — `getVersionOrDefault("targetSdk", "35")`). Nothing in the project overrides this.

**Why it doesn't meet the requirement:** SDK 54 shipped before API 36 enforcement; its Gradle defaults are pinned at 35.

### Two paths forward (NOT applied automatically, per instructions)

**Option A — Minimal, recommended given the deadline (config-only):**
Stay on SDK 54 and bump the SDK levels via the official `expo-build-properties` plugin. React Native 0.81 was the first Android-16-ready RN release, and the project already runs edge-to-edge (`edgeToEdgeEnabled=true`), which is the main Android 16 behavioral change.

```json
// package.json: npm install expo-build-properties@~54.0.0
// app.json plugins:
["expo-build-properties", { "android": { "compileSdkVersion": 36, "targetSdkVersion": 36 } }]
```

Breaking-change notes: predictive back becomes enforced at API 36 (`predictiveBackGestureEnabled: false` will be ignored by the OS — the app already handles back via expo-router, but test it). Otherwise no code changes expected.

**Option B — Major upgrade to Expo SDK 55** (RN 0.83, React 19.2, targets API 36 natively):
Larger blast radius — breaking changes include: `edgeToEdgeEnabled` config removed (edge-to-edge mandatory), `expo-blur` prop rename, `expo-router` headless-tabs `reset`→`resetOnFocus`, Hermes v1 option, and every native dependency (incl. `react-native-android-widget`, NativeWind, Reanimated) must be re-validated. **Not recommended 8 days before deadline.**

**Nuance:** If the AAB is submitted **on or before Aug 30, 2026**, API 35 is still accepted. Review queues make this risky; Option A is the safe play.
